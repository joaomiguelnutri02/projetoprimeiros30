Política de Privacidade
Projeto Primeiros 30

Esta Política de Privacidade descreve como os dados pessoais dos participantes do Projeto Primeiros 30 são coletados, utilizados e protegidos.

1. Coleta de informações

Durante a inscrição e participação no Projeto Primeiros 30, podem ser coletadas informações pessoais necessárias para a prestação do serviço.

Entre os dados coletados podem estar:

  • nome completo
  • endereço de e-mail
  • informações de pagamento
  • dados fornecidos durante o acompanhamento nutricional
  • registros alimentares realizados no aplicativo WebDiet
  • comunicações realizadas nos grupos do programa

Essas informações são utilizadas exclusivamente para o funcionamento do programa e prestação do acompanhamento nutricional.

2. Uso das informações

As informações coletadas podem ser utilizadas para:

  • realizar a inscrição e gestão do programa
  • fornecer orientações nutricionais personalizadas
  • acompanhar a evolução do participante
  • organizar atividades e funcionamento do desafio
  • enviar comunicações relacionadas ao programa
  • melhorar a experiência dos participantes

Os dados não são utilizados para finalidades diferentes das informadas nesta política.

3. Compartilhamento de dados

Os dados pessoais dos participantes não serão vendidos, alugados ou compartilhados com terceiros sem autorização.

Algumas informações podem ser processadas por plataformas utilizadas no funcionamento do programa, como:

  • plataformas de pagamento
  • plataformas de hospedagem do site
  • aplicativos utilizados no acompanhamento nutricional

Esses serviços possuem suas próprias políticas de privacidade.

4. Armazenamento e proteção de dados

Os dados coletados são armazenados em ambientes seguros e utilizados apenas pelo responsável pelo programa e pelas plataformas necessárias para o funcionamento do serviço.

São adotadas medidas razoáveis para proteger os dados pessoais contra acesso não autorizado, perda ou divulgação indevida.

5. Direitos do titular dos dados

De acordo com a Lei Geral de Proteção de Dados (LGPD), o participante possui direito de:

  • solicitar acesso aos seus dados pessoais
  • solicitar correção de dados incorretos
  • solicitar exclusão de dados quando aplicável
  • solicitar informações sobre o uso de seus dados

Solicitações relacionadas a dados pessoais podem ser feitas através dos canais de contato informados nesta página.

6. Uso de cookies

O site pode utilizar cookies ou tecnologias similares para melhorar a experiência de navegação e entender como os visitantes utilizam a página.

Cookies são pequenos arquivos armazenados no dispositivo do usuário que ajudam a otimizar a navegação.

O usuário pode optar por desativar cookies nas configurações do navegador.

7. Links para sites externos

O site do Projeto Primeiros 30 pode conter links para plataformas ou serviços externos.

A responsabilidade pelas políticas de privacidade desses sites é dos próprios serviços.

8. Alterações nesta política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir mudanças nos serviços ou exigências legais.

Sempre que houver alterações relevantes, a versão atualizada será publicada nesta página.

9. Contato

Em caso de dúvidas sobre esta Política de Privacidade ou sobre o tratamento de dados pessoais, o participante poderá entrar em contato através do canal oficial informado na página do programa.

10. Aceitação da política

Ao se inscrever no Projeto Primeiros 30, o participante declara que leu e concorda com esta Política de Privacidade.
